## 1. 公司及业务背景

### 1.1 公司概况

- 公司：联宝（合肥）电子科技有限公司，简称“联宝科技”，英文简称“LCFC”。
- 成立时间：2011 年。
- 股权关系：联想集团控股子公司。
- 总部：合肥经济技术开发区。
- 占地面积：457 亩。
- 研发基地：合肥、台北、深圳、昆山。
- 四项核心能力：创新研发、智能制造、敏捷供应、卓越质量。
- 主要业务线：个人电脑、服务器、智能设备与方案。
- 2023 年 1 月获得“灯塔工厂”认证；公司简介同时列示国家智能制造示范试点企业、国家级工业设计中心、国家级绿色工厂、国家卓越级智能工厂等资质。

### 1.2 业务板块

| 业务板块 | 文档中已明确的业务现状 |
| --- | --- |
| 个人电脑 | 年生产能力 4,000 万台套；累计出货量超过 3 亿台；产品销往 126 个国家和地区；公司简介称其为联想集团全球最大的 PC 设备研发和制造基地。已推出百余款 AIPC，并开展 ARM 等多模态、多平台开发。 |

| 智能设备与方案 | 作为第二增长曲线的先锋板块，覆盖智能算力设备、智能制造解决方案、特种机器人、车载域控与智能座舱、增值服务解决方案等业务。 |

### 1.3 运营与供应链特征

- 全球供应商超过 500 家，其中 70 余家供应商落地安徽，已初步形成“4 小时产业圈”。
- 财务分析材料同时覆盖合肥（HF）与越南（VN）基地，并对两地损益、制造增值成本、产能、库存及交易安排进行比较分析。
- 现有业务涉及联宝海外工厂/EMS、联想自有工厂、联想海外 EMS 等多种生产与交易场景；样例材料中出现 CN06、HK08、HK11、VN01 等交易主体标识。
- 公司简介列示：连续六年营收、产值均超过人民币 1,000 亿元，连续五年位列安徽民营企业百强榜首。

### 1.4 战略背景

- 公司定位：“One Lenovo New LCFC”。
- “战略 2.0”方向：主业卓越、多极增长、智赋内核。
- 公司目标：成为人工智能时代行业领先的智能设备、解决方案与服务提供商。

## 4. 当前主要财务流程

### 4.1 月度财务复盘

《September Financial Review》显示，现有复盘会议至少包括以下环节：

1. Action Recap：复核既有行动项及进展。
2. 当期财务总结：按业务板块回顾财务表现、关键指标及高光/低光事项。
3. 下一期间展望：更新财务 Outlook、关键关注点和下一步行动。
4. Wrap Up：会议收口。

样例议程将“行动回顾”“当期财务总结”“下一期间展望”分别安排为独立时间段，说明财务复盘同时承担回顾、预测和行动跟踪功能。

### 4.2 行动项跟踪

现有模板使用以下字段跟踪跨期事项：

| 字段 | 模板中的含义 |
| --- | --- |
| Action Item | 需要推进的具体事项 |
| Progress Update | 当前进展或阶段性结果 |
| Status | 状态 |
| Owner | 责任人 |

行动项示例覆盖库存管理、海外业务/交易模式、越南服务器制造增值成本、IDSG 业务推进等主题。

### 4.3 财务总结与滚动展望

- 以 PCBG、Server、IDSG 为主要业务板块形成 Executive Summary。
- 同时呈现历史/当期表现与后续期间 Outlook。
- 使用 Budget、Target、Actual、Forecast/FCST、Asp1、Asp2、CtC、OL 等多个比较口径或版本。
- 按 Highlight、Lowlight、Key Focus、Next Step 组织管理层叙事。

### 4.4 经营与损益分析

- 按业务板块分析收入、出货/产量、成本及 PTI 等损益项目。
- 按合肥与越南基地拆分 Server P&L，并分别制作 PTI Bridge。
- 按业务或产品系列拆分 PCBG Revenue。
- 对 IDSG 按 VAS、CFC、IMS、MaaS、AIoT 等业务线展示 P&L 概览。
- 使用 Bridge/Waterfall 方式解释 Budget、Target 或前一版本到当前 Outlook 的差异驱动。

### 4.5 制造增值成本分析

- 使用 MVA CPB 作为核心分析对象，并按合肥、越南基地比较。
- 驱动因素包括业务量、产品组合、汇率、折旧、线体租金、直接人工与间接人工、物流、WCC、E&O 等。
- 样例材料进一步将越南相对合肥的特有成本因素与改善行动放在同一页跟踪。

### 4.6 NRE 与项目组合分析

- 跟踪 NRE CPP Outlook。
- 展示项目组合数量，并按 LNB、TNB、DT、CB 等产品/项目类型拆分。
- 分析人工、第三方费用、样机、项目节奏及项目组合变化等驱动因素。

### 4.7 库存管理

- 使用库存金额、DOI、90 天以上库存等指标。
- 按业务线、物料/产品属性和基地分析库存结构。
- 结合产能约束、节假日备货、开放订单、预投产、调拨/退运等因素形成库存 Outlook。
- 将库存降低机会、行动、预期金额影响与风险并列呈现。

### 4.8 应收账款管理

- 跟踪应收账款余额、逾期金额和逾期比例。
- 按客户或事项记录逾期原因、预计收回时间和跟进动作。

### 4.9 业务模式与交易主体分析

- 区分联宝海外工厂/EMS、联想自有工厂、联想海外 EMS 等场景。
- 按物料集结地、生产地、目的地与交易主体梳理交易流。
- 样例材料关注关联交易、退运和关税等因素对交易安排的影响。

## 7. 当前报表与分析方式

### 7.1 报告结构

| 层级 | 当前内容 |
| --- | --- |
| 管理层摘要 | Executive Summary；按 PCBG、Server、IDSG 汇总 Highlight、Lowlight 和关键结论 |
| KPI | PC Key Function KPI；区分 Common 与 HF/VN Site |
| 损益与展望 | Financial OL、P&L、Revenue Breakdown、PTI Bridge |
| 成本 | MVA CPB Outlook 与 Bridge；HF/VN 对比；制造成本改善行动 |
| 研发/项目 | NRE CPP Outlook、Portfolio Project Qty.、分产品类型 NRE Review |
| 营运资金 | Inventory、DOI、AR Overdue |
| 执行跟踪 | Action Follow Up、Key Focus、Next Step、Owner、Status |
| 备份明细 | AR、PC、NRE、Server、IDSG 等 Back Up 页面 |

### 7.2 主要分析方法

- 实际/预测与预算、目标或上一版本对比。
- 分业务、分产品、分项目、分基地的层级拆解。
- Bridge/Waterfall 差异归因。
- 金额、比率与单位成本结合分析，例如总额、DOI、CPB、CPP。
- Highlight/Lowlight 管理层摘要。
- “问题—原因—行动—责任人—状态”的行动跟踪。

### 7.3 报告输出格式

- 当前样例为 71 页 PowerPoint 月度财务复盘材料。
- 中英文混合使用，指标和业务缩写较多。
- 核心页面由摘要文本、表格、趋势图、Bridge 图、行动列表和备份明细构成。

## 9. 当前主要痛点

以下项目均来自 2025 年 9 月财务复盘样例，属于当期被跟踪的问题或限制。

### 9.1 产品主数据无法直接支持代际拆分

- Gaming Gen11 沿用 Gen10 的 MT Code。
- Lenovo MT Code 与 LCFC PLM Code 一一匹配，LCFC 数据库依赖 PLM Code 识别产品信息。
- 由此产生按产品代际拆分 CA、Revenue、NRE 的困难。
- 当时方案是系统口径将 Gen11 合并到 Gen10，并由人工支持代际拆分。

### 9.2 库存受多因素联动影响

- 样例库存 Outlook 同时受到节假日备货、SMT 产能约束、开放订单、非齐套、越南库存回运等因素影响。
- 开放订单的控制与 CA、OTS、ONS 等业务指标存在联动，材料明确记录了控制难度。
- 库存降低需要跨组织协调 CPU、SSD、Memory、产能安排和基地间物料流转。

### 9.3 合肥与越南制造成本存在结构差异

- 样例分析显示越南基地相对合肥存在人工、折旧、产地租金、线体投资、采购成本、能源分摊等特有影响因素。
- 改善行动涉及间接人工比例、自动化线体、抽测策略、排产、电费和设备租赁等多类运营动作。

### 9.4 应收账款逾期需要逐项跟进

- IDSG 样例按客户/事项跟踪逾期金额、原因和行动。
- 材料中的原因类型包括开票延迟、客户付款延迟及合同/交易条款等。

### 9.5 新业务与新模式需要同步建立流程及系统能力

- 样例 Key Focus 包括业务上线前的系统测试、交易流设计、出区迁移、ODM+ 业务/系统流程搭建，以及相关 IT/研发投入预算审批。
- 这些事项显示，新业务落地同时依赖财务、交易、系统、预算和产能准备。
