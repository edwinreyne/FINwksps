# 用户画像与待完成工作

## 1. 使用说明

下列角色来自已确认的目标用户及公司组织语境。痛点和未来行为在未有访谈证据处标记为**设计假设**，后续需通过 CFO、FP&A、Finance BP、经理和分析人员访谈验证。

## 2. 角色画像

### 2.1 CFO / 财务领导

- **工作任务：**识别重大经营偏差与风险；比较方案；配置 OPEX、HC、Capex；作出或升级授权；监督关键行动和价值实现。
- **设计假设—痛点：**重大事项散落于报告、邮件和会议；结论与底层证据跳转成本高；审批后缺少统一的价值追踪。
- **未来方式：**从 Executive Cockpit 进入按金额、风险、时限排序的 Decision Case；查看摘要、反方观点和权限条件；审批后持续关注例外而非逐项催办。
- **需要避免：**用 Agent 摘要代替管理判断；只展示单一推荐而隐藏替代方案。

### 2.2 FP&A / 绩效管理

- **工作任务：**预算和滚动预测；实际与目标/上一版本比较；驱动因素分析；形成管理材料、建议和预测准确性复盘。
- **设计假设—痛点：**数据准备、口径确认、PPT 叙事和行动跟踪断裂；预测调整依据难以跨版本保留。
- **未来方式：**将数据版本固化为 Evidence，使用 Insight 和 Option 组织分析；人工覆盖 Agent 建议时填写原因；发布后自动创建准确性验证。

### 2.3 Finance BP / 经营财务

- **工作任务：**解释业务变化；发起资源申请；量化资源与经营结果关系；协调业务负责人执行。
- **设计假设—痛点：**申请材料标准不一；资源影响与战略优先级难横向比较；获批后使用进度与效果分离。
- **未来方式：**在统一 Case 模板中提交基线、假设、方案和证据；响应补件；把批准条件直接转为行动和监控指标。

### 2.4 财务经理

- **工作任务：**分配分析任务；复核口径和结论；审批权限内事项；处理或升级例外；保障 SLA。
- **设计假设—痛点：**难以判断材料是否齐备；工作量、阻塞和到期风险不透明；复核意见未结构化沉淀。
- **未来方式：**从 My Work 查看待复核、待审批、阻塞和即将超时事项；以质量门检查证据、假设、职责分离和阈值。

### 2.5 财务分析人员

- **工作任务：**上传和映射数据；校验来源；执行差异/驱动分析；维护模型、规则、指标口径和知识；验证行动结果。
- **设计假设—痛点：**手工整理耗时；同一数据被多次复制；结论与使用的数据快照难复现。
- **未来方式：**在 Data Center 建立有版本的模拟数据集；将证据附加到 Case；审核 Agent 草稿并记录人工判断。

### 2.6 系统管理员 / 审计人员（支撑角色）

- **工作任务：**维护角色、阈值、代理、保留策略和连接器配置；按条件检索审计事件并导出证据包。
- **边界：**管理员不因技术管理权自动获得敏感业务内容；审计只读，导出需留痕。

## 3. 跨角色核心 Jobs-to-be-Done

| 情境 | 任务 | 可验证结果 |
| --- | --- | --- |
| 指标出现重大偏差 | 我需要快速确认口径、驱动和影响 | 形成带来源、假设和置信度的 Insight |
| 预测驱动变化 | 我需要比较系统建议与人工调整 | 预测版本获批发布且覆盖原因可追踪 |
| 业务提出资源需求 | 我需要横向比较“不做/部分/全额”等方案 | 授权条件明确并转成可监督行动 |
| 管理回顾形成决定 | 我需要把讨论结论落实到负责人和期限 | 每项行动关联 Case、价值指标和升级规则 |
| Agent 建议或拟执行 | 我需要知道它为何这样做以及权限边界 | 可查看依据、模型/提示版本、工具范围并可停止 |
| 结果偏离承诺 | 我需要判断是假设错误、执行问题还是外部变化 | Verification 记录差异归因和复盘知识 |

## 4. 日常工作流

- **领导：**Cockpit → 高风险/高价值 Case → 方案比较 → 审批 → 例外/价值监督。
- **经理：**My Work → 分派/复核 → 阈值与职责检查 → 审批或升级 → SLA 管理。
- **分析/BP：**My Work 或业务域入口 → 新建/更新 Case → 证据与分析 → 提交 → 执行协同 → 验证。
- **管理员/审计：**Administration → 配置或审计检索 → 受控变更/导出 → 留痕。

## 5. 体验与可访问性需求

- 中英文业务术语可并列，指标缩写应悬浮解释。
- 金额、期间、版本、实体、币种和模拟数据标签始终可见。
- 颜色不作为状态唯一表达；关键操作需要文本、图标和确认。
- 每个待办说明“为何给我、需做什么、何时到期、后续影响”。
