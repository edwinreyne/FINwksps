# Authoritative Requirements

本目录是 FIN Workspace 的权威业务需求来源：

- [用户画像与工作](personas-and-jobs.md)：目标角色、任务、痛点假设和未来工作方式。
- [MVP 需求](mvp-requirements.md)：功能/非功能需求、非范围及可测试验收标准。
- [核心工作流](core-workflows.md)：三条端到端流程及人、Agent、系统责任边界。

如架构或参考资料与本目录冲突，以本目录为准；未确认内容须标为“设计假设”或“未决问题”。
