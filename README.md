# FIN Workspace 可运行原型

这是一个完全使用合成数据的静态 Web 原型，不连接真实企业系统、模型或执行工具。

## 运行

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 演示重点

- CFO Cockpit 与 FP&A Analyst Workbench 双角色体验。
- Server VN MVA Outlook Decision Case 的数据、分析、方案、审批、追踪和事后评价闭环。
- 人工执行、Agent 草拟及 Agent 模拟执行之间的任务级切换。
- 其余模块提供明确标记的入口和能力介绍。
